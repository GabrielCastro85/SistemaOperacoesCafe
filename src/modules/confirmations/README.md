# Confirmacoes De Negocio

Modulo da etapa 9 para criar confirmacoes manualmente ou a partir de operacoes/notas fiscais.

Inclui participantes com snapshot, itens com decimal exato, templates, clausulas, condicoes de pagamento, entrega, signatarios, previa, emissao PDF numerada, importacao de PDF assinado externamente, cancelamento, substituicao, indicadores e relatorios.

Arquivos sao gerados ou copiados pelo processo principal em `userData/documents/confirmations`, com hash SHA-256 e abertura por ID interno.
